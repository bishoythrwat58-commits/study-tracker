# 📚 مشروع متابعة المذاكرة وإشعارات أولياء الأمور

## 📁 محتويات المشروع:
- **index.html**: الصفحة الرئيسية ونموذج التسجيل والدخول.
- **app.html**: لوحة تحكم الطالب (إضافة ومتابعة المهام + إرسال واتساب تلقائي).
- **admin.html**: لوحة الأدمن لمشاهدة جميع الطلاب وأرقام هواتف أولياء أمورهم.
- **config.js**: ملف إعدادات قاعدة البيانات السحابية Supabase.
- **schema.sql**: كود إنشاء الجداول السحابية.

## 🚀 كيفية الرفع على Vercel:
1. انشئ حساب مجاني على Supabase وانسخ مفاتيح الربط وضعها في `config.js`.
2. ارفع هذا المجلد إلى مستودع GitHub.
3. اربط المستودع بـ Vercel واضغط Deploy.
